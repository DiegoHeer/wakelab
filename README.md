# wakelab

**Wake and sleep your whole homelab from the CLI.**

`wakelab` provides the `wake` command: Wake-on-LAN plus SSH control for a group
of home servers.

## Install

_Coming soon:_

```
brew install DiegoHeer/tap/wakelab
```

## Build from source

```
git clone https://github.com/DiegoHeer/wakelab
cd wakelab
make build
./bin/wake --help
```
